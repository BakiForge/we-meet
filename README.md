## About

**weMeet** is a web development project built with React and Vite. The project focuses on building a modern web interface, organizing an application into reusable components, handling forms, and implementing client-side navigation.

The project is part of my journey toward becoming a full-stack developer, allowing me to apply React concepts and develop practical frontend engineering skills.

## Features

- **Component-Based Architecture** — Building the interface with reusable React components.
- **Client-Side Routing** — Navigating between application pages using React Router.
- **Form Handling** — Managing form inputs and submissions with React Hook Form.
- **Modern React** — Using React 19 and functional components.
- **Fast Development Environment** — Powered by Vite for a streamlined development workflow.
- **Code Quality** — ESLint integration for identifying potential issues and maintaining consistent code.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/BakiForge/we-meet.git
```

**2. Navigate to the project directory**

```bash
cd we-meet
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Vite will display a local URL in your terminal, usually:

```text
http://localhost:5173
```

Open that address in your browser to access the application.
